# 디자인 시스템 — Lounge 뷰어

## 무엇을 만드는가

터미널 옆에 띄워두고 **가끔 흘깃 보는 상황판**이다. 계속 응시하는 화면이
아니다. 그래서 판단 기준은 하나 — 2초 안에 "지금 누가 있고 내가 볼 게
있나"가 읽히는가.

공항 출발 안내판이나 스튜디오 재실등에 가깝다. 대시보드가 아니다.
차트도 KPI 카드도 없다.

## 원칙

1. **재실이 주인공이다.** 화려함은 여기 한 곳에만 쓴다. 나머지는 조용하게.
2. **색은 상태만 말한다.** 장식으로 쓰지 않는다. 색이 붙어 있으면 의미가 있다.
3. **읽지 않아도 되는 것은 줄인다.** 처리된 항목은 흐려지고 물러난다.
4. **움직임은 변화가 있을 때만.** 새 항목 도착과 재실 변화, 그 둘뿐.

## 색

| 이름 | light | dark | 쓰임 |
|---|---|---|---|
| `ink` | `#16202B` | `#E4E8ED` | 본문 |
| `muted` | `#5E6E7E` | `#8C9AA8` | 보조, 시각 |
| `paper` | `#E9ECEF` | `#141A21` | 바탕 |
| `card` | `#FFFFFF` | `#1C242E` | 카드, 행 |
| `line` | `#D3D9DF` | `#2A3440` | 경계선 |
| `live` | `#1F9D76` | `#3FBF95` | 재실, 처리됨 |
| `signal` | `#C08A15` | `#E0A82E` | 미확인, 대기 |
| `alert` | `#A8382E` | `#D4564A` | 뒤집힘, 비정상 종료 |

`ink` 는 순수 검정도 `#111` 도 아니다. 두 값 모두 화면에서 탁하게 보인다.
남색이 살짝 섞여야 종이 위 잉크처럼 읽힌다.

**색을 직접 쓰지 않는다.** 상태에는 `tone` 이 붙어 있고 UI는 tone만 본다.

```
open → signal   resolved → live   superseded → alert   dropped → muted
applied → live  skipped → muted   blocked → signal
active → live   left → muted      abandoned → alert
```

이 표는 `packages/core/src/tokens.ts` 에 있다. 화면 코드에 상태별 색을
적으면 안 된다.

## 타이포

**Pretendard 하나.** 한글과 라틴 문자의 높이가 맞고 굵기 단계가 충분하다.
한글 UI에서 두 벌을 섞으면 기준선이 어긋난다.

```
display  20px / 600   프로젝트 이름
title    15px / 600   항목 제목, 섹션
body     14px / 400   요약, 본문
meta     12px / 400   시각, actor, 경로
```

굵기는 400과 600 둘뿐. 500은 한글에서 400과 구분이 안 되고 700은 무겁다.

**mono 는 ID와 파일 경로에만.** `entry.id`, `refs[].path`, 커밋 해시.
라벨이나 제목에는 쓰지 않는다.

**문장부호형 표기를 쓰지 않는다.** 가운뎃점으로 메타를 잇거나, 대문자
꼬리표를 제목 위에 얹거나, 버튼 뒤에 화살표를 붙이지 않는다.

```

├────────────────────────────────────────────┤

├────────────────────────────────────────────┤

│         로그인 API 응답 스펙 확정          │  타임라인

```

**단은 하나.** 좌우로 나누면 시선이 갈라지고 흘깃 보기 어려워진다.
상세는 오른쪽에서 밀려 나오는 패널로 띄운다.

재실 패널은 **항상 펼쳐져 있다.** 접히면 존재 이유가 사라진다.
사람이 없으면 자리를 비워두지 말고 "아무도 없습니다"를 쓴다.

## 간격

4의 배수만 쓴다. `4 8 12 16 24 32`.
항목 행 사이 `12`, 섹션 사이 `24`, 카드 안쪽 `16`.

모서리는 `6px` 하나. 카드마다 다른 값을 쓰면 위계가 아니라 소음이 된다.

## 상태 표시

**점은 재실에만.** 8px 원, `live` 는 채움, 나머지는 테두리만.
항목 상태는 점이 아니라 오른쪽 끝 작은 글자로 쓴다 — 점이 두 종류가 되면
어느 쪽이 사람인지 헷갈린다.

처리된 항목은 `opacity: 0.55`. 숨기지 않는다. 흐려지되 남아 있어야 한다.

## 움직임

두 가지만.

1. 새 항목 도착 — 위에서 `120ms` 동안 나타남
2. 재실 상태 변화 — 점이 한 번 깜박임

호버 전환, 카드 등장 애니메이션, 스크롤 연동 효과는 넣지 않는다.
`prefers-reduced-motion` 에서는 둘 다 끈다.

## 빈 화면

- 프로젝트 없음 → "프로젝트 폴더를 연결하세요" + 연결 버튼
- 라운지 없음 → "이 폴더에 라운지가 없습니다" + 만들기 버튼
- 항목 없음 → "아직 오간 내용이 없습니다"

사과하지 않고 무엇을 하면 되는지 쓴다.

## 재사용 규칙

| 하지 말 것 | 대신 |
|---|---|
| 컴포넌트에 hex 직접 쓰기 | `var(--c-live)` |
| 상태별 색 분기 코드 | `TONE[state]` from core |
| 상태 한글명 하드코딩 | `LABEL[state]` from core |
| px 직접 쓰기 | `var(--s-12)` |

새 상태가 생기면 `tokens.ts` 한 곳만 고친다. 화면 코드는 건드리지 않는다.
