뷰어의 껍데기를 바꾼다. 화면 코드와 토큰과 테스트는 그대로다.

```
브라우저  ──SSE(변경 신호) + JSON(스냅숏)──  Node 백엔드  ──읽기──  .lounge/
```

## 무엇이 바뀌나

| | 전 | 후 |
|---|---|---|
| 껍데기 | Tauri 2 (Rust) | 브라우저 + Vite |
| 파일 읽기 | 웹뷰가 플러그인으로 | 백엔드가 `nodeIO` 로 |
| 감시 | `tauri-plugin-fs` (notify) | `chokidar` |
| 전달 | 웹뷰 콜백 | SSE |
| 설치 | Rust 툴체인 필요 | `pnpm install` 뿐 |

React 컴포넌트, `tokens.ts` 소비, `styles.css`, 시간·스냅숏 테스트는 손대지
않았다. 바뀐 것은 **데이터가 어디서 오는가**뿐이다.

## 읽기 전용 세 겹은 그대로다

Tauri 권한 목록이 두 번째 겹이었다. 그 자리를 라우트 표가 맡는다.

| 겹 | 전 | 후 |
|---|---|---|
| 타입 | 뷰어가 `LoungeIO` 만 구현 | 백엔드가 `ReadonlyLounge` 만 만듦 |
| 실행 | 권한 목록에 쓰기 없음 | **쓰기 라우트 없음. GET 외 405** |
| 소스 | `/fs` import 금지 | 그대로 + 백엔드도 검사 |

`Route['method']` 는 `'GET'` 리터럴 타입이다. `method: 'POST'` 라고 쓰는
순간 컴파일이 깨진다. 규율로 참는 것이 아니다.

## 조심할 것

**CORS 헤더를 열지 않는다.** 열면 아무 웹페이지나 이 서버로 로컬 파일을
읽어 갈 수 있다. `127.0.0.1` 에만 묶고 `Access-Control-Allow-Origin` 을
두지 않는 것이 방어의 전부다. 테스트가 이 헤더의 부재를 검사한다.

`?project=` 로 임의 경로를 읽을 수 있는 것은 의도된 것이다. 루프백 + CORS
없음이 전제이므로 **이 서버를 밖으로 노출하면 안 된다.**

## 포트는 남긴다

`LoungeIO` 를 뺀 원래 이유(웹뷰에 Node 없음)는 사라졌다. 파일을 읽는 쪽이
이제 전부 Node다. 그래도 남긴다 — 읽기와 쓰기를 타입으로 가르는 수단이
여기서 나오고, 파일 없이 메모리로 갈아 끼워 시험할 수 있다.
**이유가 바뀌었을 뿐 구조는 값을 한다.** `ARCHITECTURE.md` 에 그렇게 적었다.

## codex 에게

`packages/mcp` 에는 영향이 없다. `@lounge/core/fs` 의 `openLounge()` /
`discoverLounge()` 는 그대로다.

다만 **P3 의 포장 항목이 달라진다.** `.mcpb` 나 Tauri 번들 대신, 뷰어는
`pnpm install && pnpm --filter @lounge/viewer dev` 로 뜬다.
