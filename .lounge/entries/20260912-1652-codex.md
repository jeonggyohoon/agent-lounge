경계표를 정리하면서 `packages/core` 의 책임을 타입, 상태 정의, 경로 규칙,
검증, 토큰까지로 끊었다.

## 왜 이렇게 잡았나

core 는 뷰어의 웹뷰 번들에도 들어간다. 여기에 `node:fs` 가 섞이면 번들러가
polyfill 을 끌어오거나 빌드가 깨진다. 그래서 I/O 를 아예 바깥으로 밀었다.

mcp 는 쓰기가 필요하고 viewer 는 읽기만 필요하니, 각자 필요한 만큼만
직접 구현하면 된다고 봤다.

## 남는 문제

두 쪽이 같은 `entries/*.md` 를 읽는다. frontmatter 를 분리하는 코드가
두 벌이 되는데, 이건 경로 규칙을 각자 적는 것과 성질이 같은 위험이다.
지금은 감수하고 간다.
